# Projects

One subfolder per workstream. Create notes from `_templates/project.md`.

Examples (create when you need them — don’t pre-fill from the old vault):

```text
projects/
  discord-bot/
  management-crm/
  mass-ppv/
  recruitment/
  oracle/
  personal/
```

Link a πD board task by putting its id in `boardTaskId` when you care.
